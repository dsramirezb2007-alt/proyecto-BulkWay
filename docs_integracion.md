# Integración BulkWay

La aplicación está organizada alrededor de una operación de productos de aseo y distribución. La portada presenta el catálogo y el flujo logístico; los paneles separados permiten administrar pedidos, productos, inventario, facturación, personal, rutas, entregas y clientes.

La implementación conserva React/Vite, autenticación por roles y la opción de trabajar con Supabase o JSON Server local.
